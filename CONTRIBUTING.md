# Contributing to DOGORA

Thank you for your interest in DOGORA.

## How to Contribute

- Share ideas and suggestions
- Report bugs or documentation issues
- Improve documentation
- Suggest community initiatives
- Submit focused pull requests

## Guidelines

1. Be respectful and constructive.
2. Keep discussions relevant.
3. Do not submit secrets or private credentials.
4. Explain changes clearly in pull requests.
5. Verify information before presenting it as official.
